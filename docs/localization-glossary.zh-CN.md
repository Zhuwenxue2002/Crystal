# 水晶传奇汉化术语表

本文档用于统一 Crystal Mir2 汉化过程中的中文译名。第一版以 1.76 经典传奇常用叫法为主，并参考 21cq 资料库；`bk5.176170.xyz` 当前无法稳定读取，后续可在拿到页面内容后补充。

## 参考来源

- 21cq 1.76 传奇资料数据库：https://www.21cq.com/mir/
- 21cq 战士技能页：https://www.21cq.com/mir/Magic.aspx
- 21cq 物品条目示例，裁决之杖：https://www.21cq.com/mir/View.aspx?id=105
- 21cq 法师技能书列表：https://www.21cq.com/mir/Item.aspx?u=26
- 21cq 套装资料页：https://www.21cq.com/mir/Suit.aspx
- 待核对资料库：http://bk5.176170.xyz/

## 翻译原则

1. 优先使用老玩家熟悉的 1.76 传奇译名。
2. 不翻译脚本命令、枚举名、文件名、协议字段、数据库内部标识。
3. UI 文本优先短句，避免固定坐标界面溢出。
4. 同一个英文词在同一语境下只保留一个中文译名。
5. 如果 Crystal 新增职业、地图或系统不属于 1.76 原版，先采用直译，再在游戏内验收时修订。

## 当前需要统一的项目用词

| 现有译法 | 统一为 | 原因 |
| --- | --- | --- |
| 公会 | 行会 | 更符合传奇语境 |
| 弓箭手 | 弓手 | UI 更短，与职业名保持一致 |
| 精神值 | 道术 | SC 在 Mir2 语境中应为道术 |
| 法力 | 魔法值 | 与 MP/技能消耗语境统一 |
| 登出 / 注销游戏 | 退出游戏 | 玩家侧按钮更自然 |
