## 版本控制边界

- `Build/` 整体被忽略，当前活动数据库和 5,873 个 `Envir` 文件不在 Git 中。
- 源码目录 `Server/Envir` 当前为空。
- 数据库翻译现在可由 Git 中的 Weblate PO 和稳定键清单管理，但仍需要匹配版本的基础数据库执行回写。
- 当前本机运行环境的第五阶段脚本成果仍无法仅凭此分支重建。
- 数据库压缩包也按约定作为发布资产管理，不提交源码仓库。

剩余交付问题是发布匹配版本的基础数据库与 `Envir` 资源包，或建立从上游资源自动生成运行目录的流程。

## 已知问题

- 既有掉落配置 `HiGreatGhoul` 引用了无法加载的 `RedDagger Q`；旧记录确认它不是汉化引入的问题。
- 物品提示仍有 47 条纯拉丁字符内容，其中包括装扮标签、专名和疑似占位文本，需要人工分类。
- 166 个物品名虽然包含中文或繁体字符，但没有可靠英文基线；Weblate 中仍按未翻译处理并提示人工确认。
- 客户端及管理端尚未完成系统化截图验收，不能仅凭语言文件覆盖率判定视觉层面完成。
